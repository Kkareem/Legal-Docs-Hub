# Visual reference

The law-office image and the Tajawal / Noto Naskh Arabic font definitions were taken from the user-provided design reference at https://lehal-hub.lovable.app on 2026-10-11. Fonts are hosted locally so page rendering does not depend on third-party font requests. Icons are SVG line icons implemented in the shared Angular IconComponent.

The reference supplies visual direction; the app retains its LegalDesk branding, authenticated workflows and real data. The public landing page connects to the existing consultation and login routes.
